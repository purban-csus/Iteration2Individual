I also created the SQL syntax that created the tables. Cloudflare required a file called 
schema.sql to be created. I set primary keys to auto incrament to avoid duplicates. Also none
of the columns allow for null values because they are needed for login validation and proper 
storage of both steps and calories values. Because of frequent edits to the table, they were set 
up to be easily dropped and created. The "IF NOT EXISTS" was particularly userful because it
allowed for the tables to be created without having to explicitly do it.

CREATE TABLE IF NOT EXISTS users (
    user_id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT NOT NULL UNIQUE,
    password TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS daily_health (
    health_id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    entry_date TEXT NOT NULL,
    steps INTEGER NOT NULL DEFAULT 0,
    calories INTEGER NOT NULL DEFAULT 0,

    FOREIGN KEY (user_id) REFERENCES users(user_id),
    UNIQUE (user_id, entry_date)
);
